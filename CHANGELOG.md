# Changelog

All notable project changes are documented here. The project follows semantic versioning beginning with the first tagged public release.

## Unreleased

## 0.4.0 - 2026-10-18

### Added

- Portable Docker Compose and nginx deployment.
- Idempotent Hermes plugin and semantic-routing patch installer.
- Public configuration, installation, upgrade, rollback, and security documentation.
- Environment-driven optional portal and service links.
- Continuous integration for frontend, Python, packaging, and portability checks.
- Transactional installation, diagnostics, safe removal, browser smoke tests,
  compatibility verification, deterministic release archives, and checksums.

### Changed

- Removed installation-specific private network addresses from runtime defaults and examples.
- Replaced the obsolete import-only build script with a portable static release builder.
